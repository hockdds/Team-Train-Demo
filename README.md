# TeamTrain: interactive demo

A live, click-through demo of TeamTrain, a web app that turns a business's own documents into short training
modules, quizzes and a cited question-and-answer assistant. Built first for training dental assistants.

This demo uses a **fictional dental office and made-up staff**. It runs entirely in your browser: nothing is
sent to a server and your changes stay on your device. Use the **Reset demo** link in the banner to start over.

- Sign in with the **Owner / manager view** or **Dental assistant view** buttons.
- Live AI writing, uploads and account management are turned off in the demo; the sample modules show what
  the AI produces.
